| Что решали | Какие варианты рассматривали | Что выбрали и почему |
| :--- | :--- | :--- |
| **Реализация Drag-and-Drop** | Pointer Events / DND API / Библиотека | **DND API + полифил**. Нативный API отлично работает на десктопе, а для мобильных устройств подключен написанный кем-то полифил (`DNDpolyfill.js`). Полифил эмулирует drag-события через touch-события, что позволило оставить единый простой код. |
| **Отрисовка сетки календаря** | Flexbox / CSS grid / `<table>` | **CSS grid + абсолютное позиционирование**. Grid идеально задает основу таблицы из дней и часов. Абсолютное позиционирование карточек (с вычислением `top` и `height` в JS) позволяет точно рендерить длительность пар и их наслоение. |
| **Хранение пар** | Backend DB / LocalStorage / куки | **LocalStorage**. Недели с его помощью хранятся локально (и потому перманентно), позволяя получать быстрый доступ всегда. |
| **Вид сетки на мобилке** | Горизонтальный скролл / выбор конкретного дня | **Выбор конкретного дня**. На смартфонах отображается только выбранный день. Переключение происходит мгновенно за счет смены классов у контейнера сетки (без перерисовки DOM). |
| **Перенос занятий на смартфонах** | Скролл при перетаскивании / Модалка выбора дня / буфер пар | **Буфер пар**. Так как на мобильных скрыты соседние дни, реализована выплывающая и фиксирующаяся внизу зона экрана. Пользователь кидает пару в буфер, переключает день и вытягивает её на новое место. |
| **Модальные окна** | Сторонние библиотеки / Только `<dialog>` / Только `<div>` | **Гибридный подход (`<div>` + `<dialog>`)**. Для сложных форм (редактирование, выбор группы) используются кастомные `<div>`. Для окна просмотра деталей внедрен нативный `<dialog>`. |
| **Сетевые запросы к API** | `XMLHttpRequest` / Axios / `fetch` | **`fetch` + `AbortController`**. Решение без библиотек. Добавлен таймаут: если сервер висит, запрос принудительно отменяется контроллером, предотвращая зависание интерфейса. |
